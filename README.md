One word, the word my ex would use to describe me: **avoidant**. It is funny because it is true, it stings because I know it, and it needs no explanation. This entry writes exactly that one word to `/output/entry.txt` for the "One Word From Your Ex" bounty on make.fun, where a judge model pairs the words two at a time and the funniest, most painfully honest word takes the whole reward.

## Run

```sh
node main.ts
```

It writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints the same word to stdout.
